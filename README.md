# 🌦️ Skyline Weather

A modern, responsive weather application that provides real-time weather information, hourly updates, and a 7-day forecast for cities around the world.

Built using HTML, CSS, and JavaScript, Skyline Weather delivers a clean dashboard with detailed weather insights and dynamic visuals based on current conditions.

## ✨ Features

- **Live Weather Data** – View current temperature and weather conditions.
- **City Search** – Search for any city to get its weather information.
- **Current Location** – Fetch weather using your device's location.
- **12-Hour Forecast** – View upcoming hourly temperatures, weather conditions, and wind speed.
- **7-Day Forecast** – Check daily weather conditions along with maximum and minimum temperatures.
- **Weather Details** – Monitor wind speed, humidity, atmospheric pressure, and visibility.
- **Sunrise & Sunset** – Get local sunrise and sunset timings.
- **Live Clock** – Displays the current time according to the selected location's timezone.
- **Auto Refresh** – Weather data automatically refreshes every 5 minutes.
- **Dynamic UI** – Weather-based visuals change according to current conditions.
- **Interactive Dashboard** – Visual humidity and wind indicators for a better overview.

## 🛠️ Tech Stack

- **HTML5** – Structure and layout
- **CSS3** – Styling, responsive layout, animations, and visual effects
- **JavaScript (ES6+)** – Application logic, API integration, and dynamic DOM updates
- **Open-Meteo API** – Weather forecasts and meteorological data
- **Open-Meteo Geocoding API** – City search and location identification

## 📸 Features Overview

### Current Weather Dashboard
Displays current temperature, feels-like temperature, weather condition, and today's high and low.

### Hourly Forecast
Provides a forecast for the next 12 hours, including temperature, weather icons, and wind speed.

### Weekly Forecast
Displays weather conditions and temperature ranges for the next 7 days.

### Atmospheric Details
Provides additional weather information such as humidity, wind speed, pressure, and visibility, along with sunrise and sunset timings.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Internet connection

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/BuiltByShivam/Whether_App.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Whether_App
   ```

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.

## 🌐 APIs Used

- [Open-Meteo Weather API](https://open-meteo.com/en/docs)
- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)

No API key is required for the weather data used in this project.
